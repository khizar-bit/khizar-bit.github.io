WRONG ANGLE STUDIOS

YouTube Publisher

A personal desktop publishing tool operated by Khizar for the Wrong Angle Studios YouTube channel. This is an app-information website, not a public upload service.

What the tool does

The local Python application uploads completed videos and Shorts to the authorized YouTube channel, applies titles, descriptions, tags and thumbnails, checks processing, manages playlists, and supports scheduling when the operator enables it.

Videos start private. Public releases are currently disabled and require separate operator authorization. The application does not offer a video-deletion operation.

Google authorization

The operator authorizes the application through Google OAuth. Google’s YouTube permission is broader than the app’s available operations and can include editing and deleting YouTube data. The app uses it for channel verification, video uploads, metadata, thumbnails, playlists and publication status.

OAuth credentials and upload-session URLs are stored in Windows Credential Manager on the operator’s computer. The public website contains no credentials, videos, private metadata, or sign-in form.
